# CalcVault — เครื่องคิดเลขลับซ่อนแอป

หน้าตาเป็นเครื่องคิดเลขธรรมดา (คิดเลขได้จริง) แต่ถ้าพิมพ์รหัสลับ 6 หลักแล้วกด `=` จะเข้าสู่ "ห้องลับ" ที่รวมแอปที่ซ่อนไว้

## วิธี build
1. ติดตั้ง Android Studio (Koala ขึ้นไป)
2. File → Open → เลือกโฟลเดอร์ `CalcVault`
3. รอ Gradle sync เสร็จ แล้วกด ▶ Run ลงมือถือ/อีมูเลเตอร์
4. ถ้าอยากได้ไฟล์ APK: Build → Build App Bundle(s)/APK(s) → Build APK(s)

## วิธีใช้
- **ครั้งแรก**: พิมพ์ตัวเลข 6 หลัก กด `=` แล้วพิมพ์ซ้ำอีกครั้ง กด `=` เพื่อยืนยัน
- **เข้าห้องลับ**: พิมพ์รหัส 6 หลัก (ไม่มีเครื่องหมายอื่น) แล้วกด `=`
  - ถ้ารหัสผิด แอปจะแสดงตัวเลขเหมือนเครื่องคิดเลขปกติ ไม่มีอะไรผิดสังเกต
- **ในห้องลับ**: ปุ่ม `+` เลือกแอปที่จะซ่อน, แตะไอคอนเพื่อเปิด, กดค้างเพื่อนำออก
- เมนู ⋮ → เปลี่ยนรหัส / ล็อก
- ออกจากห้องลับ (กดโฮม/สลับแอป) จะล็อกอัตโนมัติ และหน้าห้องลับจะไม่โชว์ในหน้าแอปล่าสุด/แคปหน้าจอไม่ได้

## ข้อจำกัดสำคัญ
Android ไม่อนุญาตให้แอปทั่วไปลบไอคอนของแอปอื่นออกจากหน้าโฮม (ต้อง root หรือเป็น Device Owner)
แอปนี้จึงทำหน้าที่เป็น "ตัวเปิดแอปลับ" — เพื่อให้แอปหายจากหน้าจอจริงๆ ให้ซ่อนไอคอนด้วย launcher ของมือถือ:
- Samsung: ตั้งค่าหน้าจอหลัก → ซ่อนแอปบนหน้าจอหลักและหน้าจอแอป
- Xiaomi/POCO: ตั้งค่า → แอป → ล็อกแอป → ซ่อนแอป
- OPPO/realme/vivo: ตั้งค่า → ความเป็นส่วนตัว → ซ่อนแอป
- หรือใช้ launcher อย่าง Nova / Niagara ที่มีฟีเจอร์ซ่อนแอป

แอปที่ซ่อนจาก launcher แล้วยังเปิดได้จากในห้องลับตามปกติ

## ถ้าลืมรหัส
ไม่มีวิธีกู้รหัส (เก็บเป็น hash) — ต้องไปที่ ตั้งค่า → แอป → เครื่องคิดเลข → ล้างข้อมูล แล้วตั้งรหัสใหม่ (รายการแอปที่ซ่อนจะหายด้วย แต่ตัวแอปเหล่านั้นไม่ถูกลบ)

## โครงสร้างโค้ด
- `MainActivity.kt` — หน้าเครื่องคิดเลข + ตั้งรหัสครั้งแรก + ตรวจรหัส
- `Calculator.kt` — ตัวคำนวณ + − × ÷ %
- `PinStore.kt` — เก็บรหัสแบบ SHA-256 + salt และรายชื่อแอปที่ซ่อน
- `VaultActivity.kt` — ห้องลับ (กริดแอป, เปลี่ยนรหัส, ล็อกอัตโนมัติ)
- `AppPickerActivity.kt` — เลือกแอปที่จะซ่อน
